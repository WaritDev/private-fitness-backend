## 🎯 Clean Architecture Layers

### 1. **Domain Layer** (Business Logic)
- **Location**: `domain/`
- **Purpose**: ธุรกิจ logic ที่ไม่ขึ้นกับ framework หรือ database
- **Components**:
  - `repositories/`: Interface ของ repository (contract)
  - `usecases/`: Business rules และ orchestration
  - `requests/`: Input DTOs
  - `responses/`: Output DTOs
  - `exceptions/`: Custom errors

### 2. **Adapter Layer** (Implementation)
- **Location**: `internal/adapters/`
- **Purpose**: Implement interfaces จาก domain layer
- **Components**:
  - `repositories/psql/`: Database implementation ด้วย sqlc
  - `rest/`: HTTP handlers (Fiber framework)

### 3. **Infrastructure Layer**
- **Location**: `internal/infrastructure/`
- **Purpose**: Technical details (DB, migrations, external services)
- **Components**:
  - `db/`: Database connection pool & sqlc code
  - `migrations/`: Database migrations

## 🛠️ sqlc Integration

### What is sqlc?
sqlc เป็นเครื่องมือ code generation ที่แปลง SQL queries เป็น type-safe Go code

### Workflow:
1. เขียน SQL schema → `internal/infrastructure/db/schema/`
2. เขียน SQL queries → `internal/infrastructure/db/queries/`
3. รัน `sqlc generate` → สร้าง Go code ใน `internal/infrastructure/db/dbmodel/`
4. ใช้ generated code ใน Repository

### Example:

**Schema** (`schema/create_users.sql`):
```sql
CREATE TABLE IF NOT EXISTS users (
    username VARCHAR(255) PRIMARY KEY,
    password_hash VARCHAR(255) NOT NULL,
    role VARCHAR(50) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**Query** (`queries/users.sql`):
```sql
-- name: GetUserByUsername :one
SELECT username, password_hash, role, created_at
FROM users
WHERE username = ?;

-- name: CreateUser :exec
INSERT INTO users (username, password_hash, role)
VALUES (?, ?, ?);
```

**Generated Code** (`dbmodel/users.sql.go`):
```go
type User struct {
    Username     string
    PasswordHash string
    Role         string
    CreatedAt    time.Time
}

func (q *Queries) GetUserByUsername(ctx context.Context, username string) (User, error)
func (q *Queries) CreateUser(ctx context.Context, arg CreateUserParams) error
```

## 🔌 Dependency Injection with Wire

### Purpose:
Google Wire เป็นเครื่องมือ compile-time dependency injection ที่ช่วยจัดการ dependencies

### Key Files:
- `internal/wire/provider.go`: ประกาศ provider sets
- `internal/wire/wire.go`: ประกาศ injector function
- `internal/wire/wire_gen.go`: Generated by wire (auto-generated)

### Example:

**provider.go**:
```go
var InfraSet = wire.NewSet(
    db.ProvideMariaDB,      // *sql.DB (MariaDB/MySQL)
    db.ProvideQueries,      // *dbmodel.Queries
)

var RepositorySet = wire.NewSet(
    psql.ProvideUserRepository,
    psql.ProvideAuthRepository,
)

var ServiceSet = wire.NewSet(
    usecases.ProvideUserUseCase,
    usecases.ProvideAuthUseCase,
)

var HandlerSet = wire.NewSet(
    rest.ProvideUserHandler,
    rest.ProvideAuthHandler,
    rest.ProvideHandler,
)
```

**wire.go**:
```go
//go:build wireinject
// +build wireinject

func InitializeHandler() *rest.Handler {
    wire.Build(
        ConfigSet,
        InfraSet,
        RepositorySet,
        ServiceSet,
        HandlerSet,
    )
    return &rest.Handler{}
}
```

### Generate:
```bash
make gen-wire
```

## 📊 Database Migrations

### Migration Files:
- **Location**: `internal/infrastructure/migrations/`
- **Format**: Go files with `Up()` and `Down()` functions

### Example:
```go
package migrations

import (
    "context"
    "database/sql"
)

func init() {
    Migrations = append(Migrations, createUsers)
}

var createUsers = &Migration{
    Title: "20251030011453_create_users.go",
    Up: func(db *sql.DB) error {
        _, err := db.ExecContext(context.Background(), `
            CREATE TABLE IF NOT EXISTS users (
                username VARCHAR(255) PRIMARY KEY,
                password_hash VARCHAR(255) NOT NULL,
                role VARCHAR(50) NOT NULL CHECK (role IN ('CUSTOMER', 'TRAINER', 'SALES', 'ADMIN')),
                created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
                updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
            );
        `)
        return err
    },
    Down: func(db *sql.DB) error {
        _, err := db.ExecContext(context.Background(), `DROP TABLE IF EXISTS users;`)
        return err
    },
}
```

### Commands:
```bash
# Create new migration
make migrate-make name=create_products

# Apply all migrations
make docker-migrate-up

# Rollback last N migrations
make docker-migrate-down step=1

# Reset all migrations
make docker-migrate-reset
```

### Loading Config:
```go
package config

import (
    "github.com/spf13/viper"
)

type Config struct {
    Port         string
    DBDriver     string
    DBHost       string
    DBPort       string
    DBUser       string
    DBPassword   string
    DBName       string
    JWTSecret    string
}

func LoadConfig() (*Config, error) {
    viper.SetConfigFile(".env")
    viper.AutomaticEnv()
    
    if err := viper.ReadInConfig(); err != nil {
        return nil, err
    }
    
    return &Config{
        Port:       viper.GetString("PORT"),
        DBDriver:   viper.GetString("DB_DRIVER"),
        DBHost:     viper.GetString("DB_HOST"),
        DBPort:     viper.GetString("DB_PORT"),
        DBUser:     viper.GetString("DB_USER"),
        DBPassword: viper.GetString("DB_PASSWORD"),
        DBName:     viper.GetString("DB_NAME"),
        JWTSecret:  viper.GetString("JWT_SECRET"),
    }, nil
}
```

## 📝 Best Practices

### 1. **Separation of Concerns**
- Domain layer ไม่ควรรู้จัก infrastructure details
- Repository เป็นเพียง interface ใน domain layer
- Implementation อยู่ที่ adapter layer

### 2. **Type Safety**
- ใช้ sqlc เพื่อ generate type-safe database code
- ใช้ DTOs แยกจาก database models

### 3. **Dependency Direction**
- Dependencies ชี้จาก outer layer → inner layer
- Domain layer ไม่ depend on adapter/infrastructure

### 4. **Testing**
- Mock repository interfaces สำหรับ unit test use cases
- Integration tests สำหรับ repository layer

### 5. **Error Handling**
- Define custom errors ใน `domain/exceptions/`
- Return meaningful errors จาก use cases
- Transform errors ใน handlers เป็น HTTP responses
